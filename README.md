# ytlingo

Расширение для **Google Chrome** и **Microsoft Edge** (Chromium): учите язык по YouTube — субтитры с переводом, подсветка произносимого слова, личный словарь по клику.

[Releases](https://github.com/Tetan4ik/ytlingo/releases) · [Сообщить о проблеме](https://github.com/Tetan4ik/ytlingo/issues)

## Возможности

- Перехват субтитров YouTube (JSON3) без отдельного API-ключа
- Оверлей над видео: несколько строк, текущая реплика выделена
- Автоперевод на русский (Google Translate, клиент `gtx`)
- Подсветка слова, которое сейчас произносится
- Клик по слову — сохранение в словарь с переводом
- Навигация ◀ / ▶ по репликам с перемоткой
- Попап «Мой словарь»: удаление, экспорт CSV, отдельное окно
- 3–11 строк субтитров на экране (настройка в попапе)

## Установка

### Из исходников (режим разработчика)

```bash
git clone https://github.com/Tetan4ik/ytlingo.git
cd ytlingo
```

1. Откройте `chrome://extensions` (в Edge: `edge://extensions`).
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → выберите папку `ytlingo` (где лежит `manifest.json`).
4. На YouTube откройте видео, **включите CC**, дождитесь статуса «Работает».

### Из архива

Соберите zip локально или скачайте из [Releases](https://github.com/Tetan4ik/ytlingo/releases):

```powershell
.\pack.ps1
```

Файл `dist/ytlingo-v1.0.zip` — распакуйте и загрузите как распакованное расширение (шаги выше).

## Использование

| Действие | Как |
|----------|-----|
| Словарь | Иконка расширения → «Мой словарь» |
| Сохранить слово | Клик по слову в оверлее |
| Экспорт | «Экспорт CSV» в попапе |
| Отдельное окно | Кнопка «В окне» |
| Число строк | Выпадающий список в попапе |

Статус инициализации — в углу страницы YouTube (`#yt-lang-helper-status`).

## Структура

| Файл | Назначение |
|------|------------|
| `manifest.json` | Manifest V3 |
| `page_script.js` | Перехват `/api/timedtext` (MAIN world) |
| `content.js` | Оверлей, перевод, словарь |
| `popup.*` | Интерфейс словаря |

Данные: `chrome.storage.local` (`savedWords`, `linesCount`).

## Требования

- Chrome / Edge 88+
- `https://www.youtube.com/*`
- Включённые субтитры (CC) на ролике

## Ограничения

- Только YouTube; перевод через неофициальный endpoint — возможны лимиты.
- Установка вне магазина — через режим разработчика или свой релиз zip/crx.
