# Донаты и GitHub

## Что важно понять

**Кнопка Sponsor на GitHub** и бейджи в README работают только с **обычной HTTPS-ссылкой** на страницу оплаты.  
**API-ключ DonatePay в репозиторий не кладут** — он для личного кабинета, скриптов и интеграций (оповещения, статистика), а не для отображения доната на GitHub.

Официальная настройка GitHub: [Displaying a sponsor button](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).

## Что использовать в ytlingo

| Цель | Решение |
|------|---------|
| Кнопка **Sponsor** | [`.github/FUNDING.yml`](../.github/FUNDING.yml) → `custom:` с URL виджета |
| Красиво в README | Бейдж Shields.io + та же ссылка |
| Сумма по умолчанию | Параметр `sum=200` в URL виджета |

Текущая страница доната (публичная, без API):

`https://widget.donatepay.ru/widgets/page/f37569d679fedd41e646b89ec8af4187d833a500fea8a9a299e21811fc28f216?widget_id=7879740&sum=200`

В кабинете DonatePay это обычно: **виджет «Страница»** или **ссылка на страницу оплаты** — её и дают зрителям/пользователям.

## DonatePay API (`donatepay.ru/page/api`)

Документация в кабинете (нужен вход). По открытым клиентам и описанию сервиса API нужен для:

- информации о пользователе;
- списка транзакций (донатов);
- тестового «фейкового» доната для проверки оповещений.

Ограничение: **не чаще одного запроса в 20 секунд** на операцию.

Типичный базовый путь: `https://donatepay.ru/api/v1/...` (передача токена — как указано в вашем кабинете на странице API, часто query `access_token` или заголовок).

### Что API **не** делает для GitHub

- Не встраивает форму оплаты в README (GitHub не выполняет ваш JS и не хранит секреты для виджетов).
- Не заменяет `FUNDING.yml`.

### Где API может пригодиться позже (опционально)

- свой бот/скрипт: «спасибо за донат» в Telegram;
- CI с секретом в **GitHub Actions → Secrets** (не в коде): выгрузка статистики, не публичная кнопка.

## Чеклист «адекватный донат на GitHub»

1. В репозитории: **Settings → General → Features → Sponsorships** — включить, если кнопка не видна.
2. В `main` лежит `.github/FUNDING.yml` с **одной стабильной** ссылкой на виджет/страницу оплаты.
3. В README — бейдж и текстовая ссылка на **тот же URL**.
4. API-ключ хранить только в DonatePay и локально; при утечке — **перевыпустить** в кабинете.
5. Проверка: открыть ссылку в режиме инкогнито — должна открыться форма DonatePay без входа.

## Безопасность

Не публикуйте API-ключ, `p-auth-token`, cookie сессии и `remember_web` в чатах, скриншотах и коммитах. Для GitHub достаточно публичной ссылки на виджет.
